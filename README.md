# kodarvia- planificador de comedores

Crea un proyecto base vacío para una aplicación web llamada Manyar.

IMPORTANTE: no desarrolles todavía ninguna funcionalidad del producto, no inventes pantallas, no añadas Supabase, backend, autenticación, base de datos externa ni datos de demostración.

Quiero únicamente una base técnica limpia y mínima sobre la que se continuará el desarrollo directamente desde el repositorio GitHub.

Configuración requerida:

React

TypeScript

Vite

Tailwind CSS

Estructura preparada para una aplicación multipantalla

Compatible con IndexedDB, Web Workers, BroadcastChannel y Vitest, que se incorporarán posteriormente

Sin Supabase

Sin Firebase

Sin APIs externas

Sin componentes innecesarios

Sin lógica de negocio todavía

Crear únicamente una pantalla inicial muy sencilla con:

Título:
Manyar

Subtítulo:
Planificador de comedores empresariales

Texto:
Proyecto en preparación

No añadas dashboard, menús, gráficos, formularios ni funcionalidad adicional.

Mantén una estructura de proyecto limpia, sencilla y fácil de continuar desde GitHub.

El proyecto debe arrancar correctamente con:

npm install
npm run dev

y debe poder compilar con:

npm run build

No desarrolles nada más por ahora.
